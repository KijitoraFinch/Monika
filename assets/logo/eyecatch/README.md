# Monika アイキャッチ

[PNG](monika-eyecatch.png) / [SVG](monika-eyecatch.svg)、1920 × 1080 px、16:9。

日本語の書体を変更した v2: [PNG](monika-eyecatch-v2.png) / [SVG](monika-eyecatch-v2.svg)。

利用者が添付した [C2 のロゴ](logo-selected.png) と
「AIエージェントのための知識管理ツールチェイン」を配置する。
背景は `#F7F8F5`。ロゴは添付 PNG をそのまま収録し、
基調色 `#303234` と調整後のアクセント `#65FF84` を保持する。

添え文はヒラギノ角ゴシック W4、42 px。SVG では文字の輪郭を収録し、
表示時のフォントのインストールを必要としない。

v2 の添え文は IBM Plex Sans JP Regular、38 px。プロポーショナルメトリクス（`palt`）を使い、
追加の字間は 0.3 px とする。ロゴ、配色、文言、配置は初回の版を保つ。

再生成は親ディレクトリの `requirements.txt`、収録した IBM Plex Sans JP、macOS のヒラギノ角ゴシック W4、
`rsvg-convert` を使い、`python assets/logo/eyecatch/build.py` を実行する。
